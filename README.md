The Alfred
The Alfred — это Android-приложение для управления задачами, которое превращает повседневную продуктивность в серию «миссий» в стилистике Бэтмена. Пользователь выполняет задачи, получает опыт (XP), повышает свой «ранг» и отслеживает прогресс с помощью встроенной аналитики.

✨ Возможности
Миссии (задачи): создание задач с названием, категорией, уровнем угрозы и дедлайном.
Система рангов: ранги от D до S, которые зависят от накопленного XP (500 XP — C, 1500 — B, 3000 — A, 5000 — S).
Уровни угрозы: каждая задача имеет уровень угрозы, который определяет количество XP за её выполнение.
Утренний ритуал (Readiness Check): ежедневная проверка готовности, которая открывает доступ к основному контенту и влияет на аналитику.
Шаблоны задач: сохранение часто используемых задач в качестве шаблонов для быстрого создания новых миссий.
Ежедневный брифинг: экран с цитатой дня и обзором предстоящих задач.
Аналитика продуктивности:
процент выполнения критических угроз;
среднее время выполнения по категориям;
недельная продуктивность.
Batcave Log: журнал выполненных задач и событий.
Тёмная тема: стилизованный интерфейс с фоном, зависящим от текущего ранга (от D до S), и цветом BatcaveBlack.
🛠 Технологии
Язык: Kotlin
UI: Jetpack Compose (Material 3)
Архитектура: MVVM (ViewModel, StateFlow)
База данных: Room (AppDatabase, TaskDao)
Навигация: Navigation Compose
Асинхронность: Kotlin Coroutines / Flow
Сборка: Gradle (Kotlin DSL)

🚀 Сборка и запуск
Требования
Android Studio (рекомендуется последняя стабильная версия)
JDK 17 или выше
Android SDK с минимальной поддерживаемой версией (уточняется в app/build.gradle.kts)
Инструкция
Клонируйте репозиторий:

git clone https://github.com/MarkMiraclee/TheAlfred.git

Откройте проект в Android Studio.

Дождитесь синхронизации Gradle.

Запустите приложение на эмуляторе или физическом устройстве:

bash

./gradlew installDebug

или используйте кнопку Run в Android Studio.

📱 Использование
Первый запуск: приложение предложит пройти утренний ритуал (Readiness Check). После его завершения откроется основной экран с ежедневным брифингом.
Создание миссии: нажмите кнопку добавления задачи, укажите название, категорию, уровень угрозы и, при необходимости, дедлайн. За выполнение начисляется XP в соответствии с уровнем угрозы.
Повышение ранга: накапливайте XP. При достижении порогов (500, 1500, 3000, 5000) ваш ранг будет повышаться, а фон приложения — меняться.
Шаблоны: сохраняйте часто используемые задачи как шаблоны, чтобы создавать их в один клик.
Аналитика: на экране Daily Briefing или в Batcave Log доступна статистика по выполненным задачам, прогрессу и продуктивности.
