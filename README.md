# 🦇 The Alfred

> *«Хороший босс, сэр, всегда знает, что происходит в его городе»*

**The Alfred** — Android-приложение для управления задачами, которое превращает повседневную продуктивность в серию «миссий» в стилистике Бэтмена. Пользователь выполняет задачи, получает опыт (XP), повышает свой «ранг» и отслеживает прогресс с помощью встроенной аналитики.

## ✨ Возможности

- **Миссии (задачи)** — создание задач с названием, категорией, уровнем угрозы и дедлайном.
- **Система рангов** — ранги от D до S, которые зависят от накопленного XP. Ранг меняет цветовую тему и фон приложения.
- **Уровни угрозы** — каждая задача имеет уровень угрозы, который определяет количество XP за её выполнение.
- **Утренний ритуал (Readiness Check)** — ежедневная проверка готовности, которая открывает доступ к основному контенту и влияет на аналитику.
- **Шаблоны задач** — сохранение часто используемых задач в качестве шаблонов для быстрого создания новых миссий.
- **Ежедневный брифинг** — экран с цитатой дня и обзором предстоящих задач.
- **Аналитика продуктивности:**
  - процент выполнения критических угроз;
  - среднее время выполнения по категориям;
  - недельная продуктивность.
- **Недельный цикл** — XP и ранг сбрасываются каждый понедельник, а итоги всех прошедших недель сохраняются в журнале.
- **Batcave Log** — журнал выполненных задач и событий.
- **Тёмная тема** — стилизованный интерфейс с фоном, зависящим от текущего ранга (от D до S).

## 🎮 Игровая механика

| Уровень угрозы | XP | Блок на Daily Briefing |
|---|:---:|---|
| 🟢 MINOR THREAT | +25 | Внизу списка |
| 🟠 MEDIUM THREAT | +75 | Средний блок |
| 🔴 CRITICAL THREAT | +200 | Верхний блок + CAVE ALERT |

| Ранг | XP | Тема приложения |
|:---:|---|---|
| **D** | 0 – 499 | Пещера |
| **C** | 500 – 1 499 | Пещера с компьютером |
| **B** | 1 500 – 2 999 | Бронза |
| **A** | 3 000 – 4 999 | Серебро |
| **S** | 5 000+ | Золото |

Каждый понедельник в 00:00 по локальному времени счёт обнуляется — неделя начинается с чистого листа, а её итог переходит в **Weekly History**.

## 📱 Экраны

| Экран | Назначение |

## 🚀 Сборка и запуск

**Требования:**

- Android Studio (рекомендуется последняя стабильная версия)
- JDK 17 или выше
- Android SDK с минимальной поддерживаемой версией (уточняется в `app/build.gradle.kts`)

**Инструкция:**

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/MarkMiraclee/TheAlfred.git
   ```

2. Откройте проект в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Запустите приложение на эмуляторе или физическом устройстве:

   ```bash
   ./gradlew installDebug
   ```

   или используйте кнопку **Run** в Android Studio.

## 📖 Использование

1. **Первый запуск** — приложение предложит пройти утренний ритуал (Readiness Check). После его завершения откроется основной экран с ежедневным брифингом.
2. **Создание миссии** — нажмите кнопку добавления задачи, укажите название, категорию, уровень угрозы и, при необходимости, дедлайн. За выполнение начисляется XP в соответствии с уровнем угрозы.
3. **Повышение ранга** — накапливайте XP. При достижении порогов (500, 1500, 3000, 5000) ваш ранг будет повышаться, а фон приложения — меняться.
4. **Шаблоны** — сохраняйте часто используемые задачи как шаблоны, чтобы создавать их в один клик.
5. **Аналитика** — на экране Daily Briefing или в Batcave Log доступна статистика по выполненным задачам, прогрессу и продуктивности.
